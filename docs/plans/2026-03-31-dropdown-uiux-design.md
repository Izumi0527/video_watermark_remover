# 下拉框 UI/UX 优化设计

**日期：** 2026-03-31

**目标：** 基于 `ui-ux-pro-max` 的“更强视觉层级”方向，统一优化桌面参数面板与日志面板中的下拉框，让组件更像设计稿中的卡片式控件，同时保持桌面工具的稳定感、可读性与可访问性。

---

## 1. 当前问题

- 现有 `QComboBox` 整体偏“表单控件默认态”，层级感不足。
- 关闭态与展开态区分不够强，缺少“可点击”“已聚焦”“正在选择”的明确反馈。
- 下拉箭头区域、边框、选中项和悬停项的视觉权重不够，导致控件存在感偏弱。
- 参数面板中的多个下拉框语义重要，但当前与普通输入控件的层级差异不明显。

---

## 2. 设计方向

本次采用“卡片式分层下拉框”方案：

- 关闭态：更圆润、更立体，强化边框、内边距和阴影，让控件像独立卡片。
- Hover 态：轻微提亮背景和边框，增强可点击反馈。
- Focus 态：提供清晰的焦点环和描边变化，满足键盘导航可见性。
- 展开态：弹出列表具备独立面板感，选中项和悬停项区分明确。
- 信息层级：关键下拉框通过统一尺寸、箭头区和选中高亮获得更强视觉权重。

风格参考来自 `ui-ux-pro-max` 的：

- `Soft UI Evolution`
- `Focus States`
- `Hover States`

这意味着本次不会走强玻璃拟态或过重动效，而是采用“轻阴影 + 清晰边界 + 可访问优先”的现代桌面工具风格。

---

## 3. 作用范围

首批覆盖以下关键下拉框：

- 高级参数面板
  - 检测方法
  - 修复算法
  - OpenCV 方法
  - 处理模式
  - 输出格式
- 日志面板
  - 日志级别

---

## 4. 具体设计决策

### 4.1 关闭态

- 增大圆角，提升卡片感。
- 增加左右内边距，避免文字和箭头拥挤。
- 提升最小高度，统一控件纵向节奏。
- 使用轻微阴影与更清晰边框，增强“控件浮于表面”的感觉。

### 4.2 Hover / Focus 态

- Hover 时边框和背景同步提亮，而不是只改边框。
- Focus 时使用更强的主色描边，并辅以轻度高亮背景。
- 不移除焦点提示，确保键盘用户可识别当前控件。

### 4.3 下拉箭头区

- 为右侧箭头区域保留独立宽度，形成明确的操作提示区。
- 箭头颜色与文字层级统一，但在 hover/focus 下保持可见。
- 避免使用过度装饰性图形，保持专业工具属性。

### 4.4 弹出列表

- 弹层边框、圆角和背景与关闭态保持同一设计语言。
- 提高条目高度与左右留白，改善扫描效率。
- 悬停项使用浅色高亮，选中项使用主色高亮，二者明确区分。

---

## 5. 实现策略

- 优先修改全局样式入口 `src/app/config/styles/sections/combobox.py`，统一所有 `QComboBox` 的主视觉。
- 对参数面板和日志面板中的关键下拉框补充 `objectName` / `toolTip` / 尺寸策略，形成更稳定的一致性效果。
- 保持现有业务逻辑不变，仅优化 UI 表达与交互反馈。

---

## 6. 验收标准

- 下拉框关闭态明显比当前更有层级感。
- Hover、Focus、展开列表都有清晰反馈。
- 右侧参数面板中的下拉框观感统一，不再像默认控件。
- 日志面板下拉框与参数面板下拉框风格一致。
- 不引入启动错误、不影响已有参数读写逻辑。
