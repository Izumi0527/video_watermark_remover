# 下拉框紧凑密度优化设计

**日期：** 2026-04-04

**目标：** 在保持当前下拉框视觉层级和可读性的前提下，收紧关闭态与展开列表的上下留白，解决“下拉框看起来偏大”的观感问题。

---

## 1. 问题定义

当前下拉框已经具备卡片式层级感，但存在两个观感问题：

- 关闭态的上下内边距偏大，导致控件显得厚重。
- 展开后的选项列表行高偏高，在参数面板中显得松散。

用户希望这两部分一起收紧，而不是只压缩关闭态高度。

---

## 2. 设计方向

本次继续沿用 `ui-ux-pro-max` 的“专业、可信、紧凑但不拥挤”的方向，采用 **均衡紧凑** 方案：

- 缩小关闭态 `QComboBox` 的垂直 padding 与最小高度。
- 同步缩小 `drop-down` 区域的上下 margin，避免箭头区显得悬浮过大。
- 缩小展开列表中每一项的垂直 padding 与最小高度。
- 保留 hover、focus、selected 的层级反馈，不牺牲可访问性。

---

## 3. 作用范围

- 全局下拉框样式：`src/app/config/styles/sections/combobox.py`
- 参数面板统一下拉框配置：`src/app/ui/widgets/advanced/advanced_parameters_widget.py`
- 日志面板紧凑下拉框：`src/app/ui/components/log_panel.py`

---

## 4. 关键决策

### 4.1 关闭态

- 将主下拉框的上下 padding 从当前值再缩一档。
- 将默认参数面板下拉框最小高度从 38 下调到更紧凑的高度。
- 日志面板的紧凑下拉框也同步下调，保证整体节奏一致。

### 4.2 展开列表

- 列表容器的内边距缩小。
- 单个条目的上下 padding 与 `min-height` 一起降低。
- 保留足够左右留白，避免中文选项在窄布局中显得拥挤。

### 4.3 验收原则

- 下拉框整体更紧凑，但文本不贴边、不发挤。
- 展开列表能在同等空间内看到更多选项。
- hover / focus / selected 状态仍然清晰。
