# 导入对话框默认媒体过滤器设计

**目标**
- 修复导入文件时默认只先显示图片的问题，让图片和视频在首次打开时一起显示。

**问题根因**
- 主导入入口 `src/app/ui/signal_handler.py` 传给文件对话框的首个过滤项是“图片文件”。
- Qt 文件对话框默认选中首个过滤项，因此用户第一次打开时只能先看到图片。
- 批量导入入口 `src/app/ui/widgets/batch/batch_file_manager.py` 已经使用“支持的文件（图片+视频）”作为首项，两个入口行为不一致。

**方案**
- 抽取统一的 UI 导入文件过滤器常量。
- 主导入入口与批量导入入口都复用同一份过滤器定义。
- 默认首项改为“支持的文件（图片+视频）”，并保留“视频文件”“图片文件”“所有文件”等次级过滤项。

**边界**
- 只修改文件选择层，不改导入后的预览、识别、处理逻辑。
- 不改导出对话框过滤器。

**验证**
- 新增单元测试，直接断言主入口传给 `QFileDialog` 的过滤器首项是联合过滤。
- 新增单元测试，断言批量文件管理器与主入口使用同一份过滤器字符串。
