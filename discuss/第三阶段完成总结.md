## 🚀 部署建议

### 环境要求
```bash
# Python环境
Python >= 3.8

# 必需依赖
PyQt6 >= 6.4.0
OpenCV >= 4.5.0
NumPy >= 1.21.0

# 可选依赖
FFmpeg (音频处理)
CUDA (GPU加速)
```

### 安装步骤
```bash
# 1. 克隆项目
git clone <repository-url>
cd video_watermark_remover

# 2. 安装依赖
pip install -r requirements.txt

# 3. 运行程序
python main.py
```

### 配置说明
- **用户配置**: `~/.video_watermark_remover/user_preferences.json`
- **日志文件**: 自动生成在用户目录
- **临时文件**: 系统临时目录，自动清理
